Agentypical · specs · listing v1

Public listing schema format_version 1

What this is

Machine-readable shape for a public Agentypical directory card. Format version: 1. Canonical JSON Schema: /specs/listing.v1.json.

Required fields

  • id — stable slug
  • name — display name
  • category — dns | email | payments | hosting | sms | identity
  • discovery_url — public URL agents can fetch
  • status — known | evaluating | certified | none_yet

Optional: website, agent_enrolment (boolean), notes (public only), updated.

Status meanings

  • known — widely known and agent-API-capable (may still have human-first account setup).
  • evaluating — promising, not fully agent-first yet.
  • certified — earned Agentypical Certified after review. Never invent.
  • none_yet — category empty on purpose.

Where listings live

Index /directory.json · per category /directory/{category}.json · submit for review /list-my-service/ (not auto-public).
